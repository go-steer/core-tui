# Acknowledged incompatible changes to the exported API since the last
# release tag. Read and enforced by dev/tools/verify-apidiff.
#
# One apidiff line per entry, exactly as the tool prints it under
# "Incompatible changes" but without the leading "- ". Blank lines and
# everything after a `#` are ignored. For example:
#
#   # #77: Options.Foo never had a caller outside the examples and its
#   # zero value was already the only supported one.
#   ./tui.Options.Foo: removed
#
# An entry here is not a rubber stamp — it is a claim, made in the PR that
# breaks the symbol, that the break is intended and written down. Record
# the same change under Changed or Removed in CHANGELOG.md.
#
# Cutting a release empties this file: once the tag moves, these breaks
# sit behind the new baseline, and a leftover entry would silently permit
# a second, unrelated removal of a symbol that no longer exists.
#
# Emptied at v0.22.0. The 14 entries that were here — #254 and #257,
# the render-extension sweep docs/api-surface.md §3.2 recommends — are
# behind that tag now, and both are written up under Removed in the
# v0.22.0 section of CHANGELOG.md. The 38 emptied at v0.21.0, from #77,
# #78 and #213, are two baselines back.

# Entries since v0.22.0 follow.

# #115: the concrete Bubble Tea model is unexported, and the constructor
# hands back tea.Model instead. The two go together — either alone is a
# break, and NewModel returning an unexported type would not compile for
# a caller. Nothing exported named Model except NewModel and its four
# methods; Init, Update and View are all on tea.Model in v2, so an
# external driver loop compiles unchanged. ApplyTranscript, the one
# method tea.Model does not cover, is replaced by the compatible
# Options.Transcript rather than dropped. Recipe in MIGRATION.md §7,
# reasoning in docs/decisions.md D18a.
./tui.Model: removed
./tui.NewModel: changed from func(Options) Model to func(Options) charm.land/bubbletea/v2.Model

# #260: the toy daemon's interrupt call learned the pause gate. It has to
# say whether it wants the hold, and its answer has to distinguish "a turn
# was cancelled" from "the loop is parked" — a bare bool cannot carry both,
# and at protocol 1.5.0 an interrupt that cancelled nothing but shut the
# gate is a success rather than the "no turn in flight" error it used to
# be. Nothing outside examples/core-agent can call this: fakehost is the
# stand-in that lets the adapter sketch compile without depending on the
# real core-agent module, and it promises nothing, the same way
# tui/testagent does. It is in this file only because the apidiff gate
# walks every package in the module, which is the behaviour we want.
./examples/core-agent/fakehost.(*Client).Interrupt: changed from func(context.Context, string) (bool, error) to func(context.Context, string, bool) (InterruptResult, error)
